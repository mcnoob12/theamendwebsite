Create a GitHub fine-grained token so this page can save entries to the repo:

  1. Open github.com/settings/personal-access-tokens/new
  2. Repository access: Only select repositories → theamendwebsite
  3. Permissions → Repository → Contents: Read and write
  4. Generate, then paste it below.

The token is encrypted with your password before it is saved. Only someone with the password can use it.
